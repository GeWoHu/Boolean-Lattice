# v1.1 changelog (2026-10-28)

Revision in response to an external referee-style checklist. The theorem,
the sharp constant k(m-k+1)/m, the equality characterization, and the
proof mechanism are unchanged; v1.0 remains tagged.

- Added an explicit up/down convention statement (U_k(a) maps level k to
  level k-1; naming does not affect any result).
- Added a notation paragraph and completed the squared-norm typography:
  all vector norms are written ||.||_2, operator norms ||.||.
- Added Proposition 3.1 comparing the theorem with general-purpose bounds
  (Schur test and Frobenius), with explicit improvement factors and
  equality cases.
- Added a remark extending the theorem verbatim to complex weights via
  diagonal unitary phase conjugation.
- Added a "Numerical ratios" section with the normalized-ratio table
  R(a) for flat, sparse, nearly flat, and random weights.
- Added verification scripts: perfect_square_exact.py (standalone exact
  arithmetic: symbolic expansion + Fraction spot checks),
  numerical_table.py, complex_weights.py. All pass.
- 6 pages -> 7 pages; rebuilt with Tectonic from the included source.
